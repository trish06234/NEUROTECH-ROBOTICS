Let’s make a step‑by‑step tutorial for building your Arduino LED project in Tinkercad Circuits.

01:Sign in to Tinkercad

You need to log in before creating circuits.

Go to tinkercad.com

Click Sign In and enter your account details

If you don’t have an account, click Join Now to register

02:Create a New Circuit

Start a fresh workspace for your Arduino project.

On the dashboard, click Create → Circuits-On the dashboard, click Create → Circuits

03:Switch Components to All To Access the full library of parts

In the right components panel, change filter from Basic to All

This lets you search for Arduino, breadboards, LEDs, and resistors

04:Add Arduino Uno R3 By Dragging the microcontroller to your workspace.

Search for Arduino Uno R3

Drag and drop it onto the canvas

05:Add a Breadboard. The breadboard is used to organize LED connections.

Search for Breadboard Small

Drag it next to the Arduino

06:Place LEDs and Resistors.Set up multiple LEDs with current limiting resistors

Search for LED and drag several (red, yellow, green)

Connect each LED in series with a resistor (220Ω–330Ω)

Place them neatly on the breadboard

07:Wire the Circuit.Connect Arduino pins to LEDs through resistors.

Use jumper wires to connect Arduino digital pins (e.g., 2–7) to breadboard rows

Connect resistors from those rows to LED anodes

Connect LED cathodes to Arduino GND

08:Open Code EditorSwitch to block coding to control LEDs.

Click Code - Blocks

Drag blocks to set pin modes and turn LEDs on/off- to learn c++ click Learn More About PROGRAMMING

09:Run the Simulation.Test your circuit virtually.

Click Start Simulation

LEDs will alternate colors according to how you set them
